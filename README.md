# CodeAlpha Java Programming Internship

## 🚀 Internship Project Portfolio

This repository contains the Java projects developed as part of my
**CodeAlpha Java Programming Internship**.

The projects demonstrate practical implementation of:

- Java Object-Oriented Programming
- Collections and data management
- Exception handling
- File handling and persistence
- GUI development using Java Swing
- Application validation
- Business logic implementation

---

## 📂 Projects

### 1. Student Grade Tracker

A Java Swing application for managing student grades and generating
academic performance summaries.

**Features**
- Add students
- Add multiple grades
- Calculate average marks
- Find highest and lowest marks
- Automatic grade calculation
- Summary report
- Input validation
- File-based persistence
- Object-Oriented design

📁 `Task 1 - Student Grade Tracker`

---

### 2. Stock Trading Platform

A Java Swing stock trading simulator that allows users to interact
with a virtual stock market.

**Features**
- Market dashboard
- Stock information
- Virtual cash balance
- Buy stocks
- Sell stocks
- Portfolio holdings
- Portfolio valuation
- Trade history
- Transaction validation
- Object-Oriented design

📁 `Task 2 - Stock Trading Platform`

> This project is a simulation and does not perform real stock-market
> transactions.

---

### 3. AI Chatbot

A Java Swing rule-based chatbot demonstrating basic Natural Language
Processing and intent matching.

**Features**
- Interactive chat interface
- Rule-based NLP
- Intent recognition
- Java/OOP questions
- Internship-related responses
- Stock-related responses
- Grade-related responses
- Hotel-related responses
- Clear chat functionality

📁 `Task 3 - AI Chatbot`

---

### 4. Hotel Reservation System

A Java Swing hotel booking application for managing rooms and
reservations.

**Features**
- Room availability
- Standard rooms
- Deluxe rooms
- Suite rooms
- Guest booking
- Check-in and check-out dates
- Automatic price calculation
- Payment simulation
- Booking confirmation
- Reservation cancellation
- Reservation persistence
- Input validation

📁 `Task 4 - Hotel Reservation System`

> Payment functionality is simulated for demonstration purposes.
