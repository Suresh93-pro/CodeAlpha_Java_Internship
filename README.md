# CodeAlpha Java Programming Internship — Final Submission Suite

Four independent Java applications are included so each internship task can be opened, run, demonstrated and submitted independently.

## Projects
1. `Task 1 - Student Grade Tracker`
2. `Task 2 - Stock Trading Platform`
3. `Task 3 - AI Chatbot`
4. `Task 4 - Hotel Reservation System`

Each task contains its own `src` folder, `README.md`, and `run.bat`.

## Requirements
- JDK 17+
- VS Code + Java Extension Pack recommended
- Windows is recommended for the included batch launchers

## Run any task
Open the task folder in VS Code and run:
```powershell
.\run.bat
```
Or:
```powershell
javac -d out src\*.java
java -cp out Main
```

## Submission note
The supplied CodeAlpha task sheet lists these four Java tasks and says interns must complete a minimum of two or three tasks. It also requests GitHub source-code submission and a LinkedIn project/video post.

Stock trading and hotel payment are simulations for educational purposes. The chatbot uses rule-based NLP/intent matching.
