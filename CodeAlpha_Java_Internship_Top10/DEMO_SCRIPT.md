# CodeAlpha Demo Script

## Opening
“Hello, I’m demonstrating my CodeAlpha Java Programming Internship projects. I implemented the assigned Java tasks as separate applications using object-oriented programming.”

## Task 1 — Student Grade Tracker
Add a student, enter grades, show average/highest/lowest, then show the summary report. Explain ArrayList, classes, validation and file persistence.

## Task 2 — Stock Trading Platform
Show market data, perform a virtual BUY, open Portfolio, perform a SELL, then show Trade History. Explain that prices/trades are simulated.

## Task 3 — AI Chatbot
Ask about Java, OOP and the internship. Explain rule-based NLP/intent matching and the separate chatbot engine.

## Task 4 — Hotel Reservation System
Show room categories, book an available room, show simulated payment, show BOOKED status, open booking details, then cancel.

## Closing
“These projects demonstrate Java OOP, collections, validation, file handling, GUI development and application logic. Financial and payment operations are simulations.”
