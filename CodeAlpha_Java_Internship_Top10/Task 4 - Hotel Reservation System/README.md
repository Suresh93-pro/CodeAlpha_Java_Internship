# Task 4 — Hotel Reservation System
Standalone Java Swing hotel reservation application.

### Features
- Standard / Deluxe / Suite rooms
- Room availability
- Guest booking
- Check-in/check-out date validation
- Prevents unavailable-room booking
- Automatic price calculation by nights
- Payment simulation
- Reservation details
- Cancellation
- Persistent `hotel.dat` storage
- OOP classes `Room` and `Reservation`

**Payment is a simulation for the internship project.**
